# CareerForge — Student Career & Internship Hub

CareerForge is a responsive frontend project created for **Project 1: Responsive Frontend Interface**.

## Technologies
- HTML5
- CSS3
- Basic JavaScript
- CSS Grid
- Flexbox
- Responsive media queries
- Semantic HTML
- Accessibility-friendly patterns

## Pages
- Home
- Career Explorer
- Skill Assessment
- Internship Hub
- Student Dashboard
- Student Profile

## JavaScript interactions
- Mobile navigation
- Light/dark theme
- Career category filtering
- Interactive career assessment
- Internship search and category filtering
- Save internship buttons
- Dashboard milestone interaction

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Project note
This is a frontend-only internship project. Internship listings and profile data are sample content for demonstration; there is no backend or real application/authentication.
